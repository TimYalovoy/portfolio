# Тестовое задание Saber Interactive на должность Gameplay Programmer  
## Задание 1
Реализуйте функции сериализации и десериализации двусвязного списка, заданного следующим образом:  
```csharp
class ListNode
{
    public ListNode Prev;
    public ListNode Next;
    public ListNode Rand; // произвольный элемент внутри списка
    public string Data;
}


class ListRand
{
    public ListNode Head;
    public ListNode Tail;
    public int Count;

    public void Serialize(FileStream s)
    {
    }

    public void Deserialize(FileStream s)
    {
    }
}
```
__Примечание__:  
Cериализация подразумевает сохранение и восстановление полной структуры списка, включая взаимное соотношение его элементов между собой. Формат сериализованного файла любой.

* Нельзя изменять исходную структуру классов ListNode, ListRand.
* Алгоритмическая сложность решения должна быть меньше квадратичной.
* Для выполнения задания можно использовать любой общеиспользуемый язык.
* Тест нужно выполнить __без__ использования библиотек/стандартных средств сериализации:
    * `BinaryFormatter`
    * `XmlSerializer`
    * `DataContractSerializer`
    * `Newtonsoft.Json`
    * `System.Text.Json`
  
  
## Использование программы

Программа принимает аргументы командной строки:
csharp_solution.exe [путь к файлу] -[режим]

Если аргументов нет, запускаются встроенные тесты. Если указан только путь к файлу, программа автоматически работает в режиме чтения (`-r`).

### Без аргументов
Запускает встроенные тесты сериализации/десериализации и выводит результаты.

Пример: csharp_solution.exe
  
  
### Режим чтения (`-r`)
Загружает файл, десериализует список и проверяет его целостность (связность Prev/Next, корректность Rand, соответствие Count).

Пример: csharp_solution.exe data.bin -r
Примечание:
  

### Режим записи (`w`)
Запускает интерактивный редактор двусвязного списка. Доступные операции:

1. **Add new Node** – добавить новый узел. Запрашивает Data, индексы Prev, Next, Rand (пустой ввод – null / пустая строка).
3. **Move Node** – переместить существующий узел. Запрашивает индекс узла, новые индексы Prev и Next.
4. **Edit Node** – изменить Data узла по индексу.
5. **Remove Node** – удалить узел по индексу.
6. **Save & Exit** – сохранить список в указанный файл и проверить его структуру.
  
**Примечание по изменению структуры списка (Add, Move, Remove):**
- Если при добавлении или перемещении узла индексы Prev и Next не указаны, узел помещается в конец списка.
- При вставке в середину (указаны индексы) весь список автоматически перестраивается для сохранения корректной двусвязной цепочки, включая обновление Head и Tail.
- При удалении узла все ссылки Rand, указывавшие на удалённый узел, сбрасываются в null.
  

При возникновении ошибок доступа к файлу (например, файл занят другим процессом) программа предложит повторить сохранение или отменить его.

Пример: csharp_solution.exe data.bin -w
